# Libreta de Equipos y Pautas

App web para la tableta Boox: bitácora de equipos de proyecto y corrección con rúbricas en escala 1,0 a 7,0.

- Funciona sin internet una vez instalada (Chrome → menú ⋮ → Instalar app).
- Los datos se guardan solo en la tableta; no se suben a este repositorio.
- La app publicada está en la rama `gh-pages`.
